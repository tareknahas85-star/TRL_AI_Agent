# تطبيق الموبايل (TRL Agent) — أندرويد

واجهة على التلفون للبرنامج اللي عالكمبيوتر: شات، اختيار الموديل/الوضع (تلقائي، مجاني، موديل، council)، موافقات الأوامر،
متابعة المهام الشغّالة، وإرسال ملفات/صور/صوت. كل شي بيتنفذ عالكمبيوتر، والتلفون بس واجهة.

## التركيب (للمستخدم)

نزّل `TRL_AI_Agent-5.17.4-android.apk` من صفحة الإصدارات وثبّتو عالتلفون، وبعدين اتبع قسم "تطبيق الموبايل" بالـ README الرئيسي (ربط بـ QR). النسخة debug وغير موقّعة بمتجر Play.

## الأمان
- ربط مرة وحدة بـ QR بيطلع بالبرنامج (الإعدادات ← تطبيق الموبايل ← ربط جهاز جديد). الـ QR صالح دقيقتين وبينفع مرة وحدة.
- رمز تأكيد من 6 أرقام بيظهر عالشاشتين، وإنت بتأكد عالكمبيوتر.
- التشفير من الطرفين (X25519 + XChaCha20-Poly1305 عبر libsodium)، بمفاتيح جلسة جديدة كل اتصال. الـ relay بيمرّر بس.
- مفتاح التلفون محفوظ بمخزن أندرويد الآمن (Keystore) وما بيطلع منو.
- الموافقات موقّعة بمفتاح التلفون ومربوطة بالأمر نفسو + مهلة، فما بتنعاد.
- بتشيل أي جهاز بضغطة من البرنامج.

## البناء
```
cd mobile
npm install
npm run bundle          # بيبني www/app.js
npx cap sync android
cd android && gradlew.bat assembleDebug     # JDK 21 + Android SDK 36
```
الـ APK بيطلع بـ `android/app/build/outputs/apk/debug/app-debug.apk`.

## تشغيل الاختبارات (بدون تلفون)
- `scripts/remote-test.ts`: اختبارات البروتوكول والتشفير والـ relay (replay، تلاعب، جهاز غريب، سر منتهي...).
- `scripts/fake-host.ts`: «كمبيوتر وهمي» بيستعملو اختبار الواجهة بمتصفح.
